# public/img

The site's own artwork. Anything here is served from `/img/…`.

`logo.png` is the mark in the top bar, shown 44 px tall. It was cut out of the
original drawing by flood-filling the black ground from the border, which is
conservative on purpose: the sabre is drawn almost as dark as the background, so
a bolder cut erased it. What survives is a thin dark fringe, invisible against
the near-black bar. If the file ever fails to load, the bar falls back to a pin.
